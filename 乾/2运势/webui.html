存储上限与分段 超过上限或跨天即开新库

      

        

          

        

          

      

      

        
      

      

        存储上限 = 单个数据库文件的大小上限，写满了就自动开一个新的库接着写

        分段周期 = 每隔几天开一个新库（1 = 一天一个新库）

        两个条件谁先到谁触发。文件名固定 yyyy-mm-dd-序号.db，同一天写满几个就编到几号。

        旧数据不自动删，库多了去下面手动删。
      

    


    

      
手动清除 删了不可恢复

      

        

        

        

          
        

      

      

        
        
        
      

      

        清空全部 = 删掉所有数据库文件，从头再来

        删最旧 N 个库 = 快速腾空间，从最老的开始删

        清空当前库 = 只清正在写入的那个，文件保留继续用

        清除时间段 = 按时间删；某个库被清空时连文件一起删掉

「服务」是两层，别混

      

        ① Web 服务 —— 就是这个页面本身。它一停，页面上所有按钮都点不动
        （网页没法启动本地程序）。它是靠 震\启动WebUI.bat 起来的。

        ② 转发引擎 —— 真正收发 MQTT 的那部分。上面的「启动 / 停止转发」管的是它。


        想让 ① 永远在、彻底不用碰 bat，最省事的是注册开机自启。这条得你自己跑
        （注册登录时自启属于系统级操作，界面不替你做）：
      

      

        schtasks /Create /TN "MQTT-Forwarder-WebUI" /TR "<python> -I <项目>\震\launch.py webui 8090 --bg" /SC ONLOGON /F
      

      

        取消：schtasks /Delete /TN "MQTT-Forwarder-WebUI" /F

        <python> 是 python.exe 的完整路径，<项目> 是本项目的目录。
        要我帮你拼好这条命令也可以，说一声。
